# History and omissions

This technical showcase was generated from the real GroomNote AI development repository. It preserves all 35 commits reachable from the three local branches and two annotated milestone tags at preparation time, including original parent relationships and both Git timestamps.

## Transformations

- Historical private documents and original READMEs were replaced or excluded. Empty documentation commits are retained.
- Original model system/correction instructions and inline model repair instructions were removed. Live analysis fails explicitly; deterministic private demo analysis is stubbed.
- Static server-generated speech copy and opening text were replaced by placeholders. Browser-visible control labels and command grammar remain as implementation evidence.
- Production URLs, account/resource identifiers and personal attribution were replaced; no original email attribution is included.
- Internal test reports, private development scripts and test dialogue/recordings were omitted. This showcase makes no claim that its modified code passes the private product's test suite.
- Original binary artwork was replaced with newly created neutral SVG placeholders. Original assets and their metadata are not redistributed.
- Branch names are retained. Tag annotations identify sanitized historical counterparts. SHA changes are a consequence of sanitization and are not claims of original release identity.

The default branch is `experiment/w07-voice-first`; `master` and `archive/w06-click-ui` retain their historical W06 positions. `backend-v0.1.0` and `web-w06-click-ui-v1` retain their historical targets after transformation.

The new final presentation commit is separate from the preserved development history and uses its actual preparation time. No remote is configured in the local review copy. Publication requires owner approval.

## Scope of verification

History verification compares every counterpart's parents and author/committer timestamps to the private source. Content verification covers exported historical blobs, commit/tag metadata and final presentation files for selected secrets, private prompt fragments, personal identifiers, original deployment URLs and excluded paths. This is not an assertion that all possible unknown secrets or inference-based business information have been eliminated.

Public source still exposes the intentionally shared architecture, command grammar, business state machine and persistence rules. MIT permits reuse of that released code. Private backups and the original W06 release remain outside this public repository.
